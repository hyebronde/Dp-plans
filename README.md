# DP Plans · วางแผนไฟและช็อตจากมุมบน

เว็บแอป (PWA) สำหรับช่างภาพและทีมถ่ายทำ ใช้วางผังห้อง ไฟ กล้อง และนักแสดงจากมุมบน ผูกภาพบล็อกช็อตเข้ากับ Shot list แล้วส่งออกให้ทีมงาน
ข้อมูลเก็บในเครื่องผู้ใช้เท่านั้น (IndexedDB) และใช้งานออฟไลน์ได้

เปิดแอป: https://hyebronde.github.io/dp-plans/
(บน iPad / iPhone: Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม)


## ฟีเจอร์
- **หน้าตา Soft Studio:** สว่าง ปุ่มนูนนุ่ม สีขาว ดำ ส้ม น้ำเงิน ใช้ไอคอนแทนตัวหนังสือ
- **รองรับ iPhone ทุกขนาด, iPad และ iPhone Duo** (จอนอก / พับครึ่ง / กางแบน) จัดหน้าจอตามท่าของเครื่อง ไม่พาดรอยพับ
- **ห้องสำเร็จรูป:** สี่เหลี่ยม, L, U, T, โถงยาว หรือนำเข้าภาพแปลนแล้วตั้งสเกล
- **วาดแบบแม่เหล็ก:** ปลายผนังดูดติด, ต่อแบบ T, ปิดห้อง, ล็อกมุม; ประตู/หน้าต่างแตะบนเส้นผนังแล้วฝังในเส้น เปิดเข้าในห้อง
- **แสงชนผนังจริง:** ลำแสงและมุมกล้องหยุดที่ผนัง ผ่านช่องประตู/หน้าต่าง ผ้าทึบ (Neg/Flag) บังแสง
- **คลังไฟ ~120 รุ่น 4 ขนาด** (จิ๋ว / เล็ก / กลาง / ใหญ่) กรองตามยี่ห้อหรือค้นหาได้, เจลเปลี่ยนสีลำแสง, ชุดไฟของฉัน
- **กริป:** เฟรมขนาดจริง 18×24 นิ้ว – 20×20 ฟุต พร้อมผ้า, Neg, Flag, Net, Butterfly, Hazer
- **คน 12 สี, กล้องไอคอน 🎥 พร้อม FOV, เล็งไปที่เป้า**
- **ป้ายบนแปลนไม่ทับกัน** มีแบบย่อ / เต็ม (แบบ DP) / ซ่อน
- **Ref board** ต่อซีน ดึงพาเลตสี ขีดทิศแสงทับภาพ
- **Shot list** ผูกกับกล้องบนแปลน แนบภาพบล็อกได้
- **ส่งออก:** PDF breakdown, PNG, ภาพแปลน, CSV สำหรับ Sheets, รายการอุปกรณ์, ไฟล์โปรเจกต์

วัตต์ของรุ่นไฟเป็นค่าประมาณ ควรเช็กสเปกกับผู้ผลิตก่อนใช้จริง

## ไฟล์
- `index.html`: หน้าตาและสไตล์
- `app.js`: ตัวแอปทั้งหมด (ไม่มี dependency และมีตัวสร้าง PDF ในตัว)
- `sw.js`: แคชสำหรับใช้งานออฟไลน์
